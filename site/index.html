Simple, private voice and video calls.

PrivateCall is a single HTML file that opens in your desktop browser. No account or installation. Exchange an invitation and a reply, verify a security code, and talk.

Download PrivateCall.html

Version 1.2.0 · Recommended browser: Google Chrome · Free and open source (MIT)

How to use it

  1. Both people download the file and open it in Chrome.
  2. One starts a call and sends the complete invitation in a chat app. The other joins and sends the reply back.
  3. Once connected, compare the six-digit security code before talking.

Read the step-by-step guide (PDF)

How it works

PrivateCall uses WebRTC for encrypted one-to-one audio and video. Calls normally connect directly between browsers; some networks require a separately configured TURN relay. Invitations travel through a separate messaging app, not a PrivateCall signaling server.

System design and implementation report (PDF) · View the source

PrivateCall is an experimental prototype. It has not been independently security-audited and should not be relied on for high-risk communications. A successful connection does not guarantee anonymity or connectivity on restrictive networks.
